# Mahima Dugar — Digital Portfolio

A responsive, creative portfolio website built with:
- HTML5
- CSS3
- Vanilla JavaScript

## Run locally
1. Open this folder in VS Code.
2. Open `index.html` in a browser.
3. For the best development experience, install the VS Code "Live Server" extension and click **Go Live**.

## Before submission
Replace the placeholder email in `index.html`:
`mahima.dugar@example.com`

Add your real:
- LinkedIn URL
- GitHub URL
- Email
- Resume/CV link if required

The three supplied photos are already placed in `assets/`.

## GitHub
Create a new repository, then from this folder:
git init
git add .
git commit -m "Create Mahima Dugar portfolio"
git branch -M main
git remote add origin YOUR_GITHUB_REPOSITORY_URL
git push -u origin main

## Deployment
This is a static website, so it can be deployed directly through GitHub Pages, Netlify, Vercel, or similar static hosting.
